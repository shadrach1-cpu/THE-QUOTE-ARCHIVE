REAL PHOTOS (optional)
----------------------
1. Put your photos in this folder (JPG/PNG/WebP, landscape or portrait, ~1600px+ wide is plenty).
   Free, licence-friendly sources: unsplash.com, pexels.com, pixabay.com
   (cities, valleys, mountains, cars, roads, oceans, forests ...)
2. List the file names in manifest.json, e.g.:
      ["valley-1.jpg", "city-night.jpg", "sports-car.jpg", "mountain-lake.webp"]
3. Every quote is then given one of your photos (always the same one for the same quote),
   and "New background" in the Post Studio cycles through them.
If the list is empty the app uses its built-in illustrated scenes.
After adding photos, do a hard refresh (Ctrl+Shift+R) so the browser picks up the new list.
