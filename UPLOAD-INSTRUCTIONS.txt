THE QUOTE ARCHIVE — V4 UPLOAD FOLDER
====================================
Everything in this folder keeps the same layout as your GitHub repository.

HOW TO UPLOAD (GitHub website, no tools needed)
1. Open https://github.com/shadrach1-cpu/THE-QUOTE-ARCHIVE
2. Add file -> Upload files
3. Drag in the CONTENTS of this folder (index.html, sw.js, v4.js, v4.css, manifest.json,
   and the photos and music folders). GitHub keeps the folder structure.
   Do NOT upload this UPLOAD-INSTRUCTIONS.txt file (harmless, but not needed).
4. Commit changes. Wait 1-2 minutes for GitHub Pages to rebuild.
5. Open the site and press Ctrl+Shift+R (hard refresh) once so the new version loads.

WHAT THIS REPLACES
- index.html and sw.js are updated; v4.js and v4.css are new files (they MUST be uploaded
  together with index.html or the new features will not appear).
- manifest.json (root) is the corrected 779-byte PWA file (the one in the repo was wrong).
- photos/manifest.json + 40 photos/illustrated-*.jpg switch on the illustrated backgrounds.
- music/tracks.json is an empty list. To add songs later: put the mp3 in /music and list it, e.g.
  [{"file":"music/my-song.mp3","title":"My Song"}]
  Only add music you own or that is licensed for public use.
